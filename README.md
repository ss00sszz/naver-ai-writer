# 네이버 AI 원고 스튜디오 — Streamlit Cloud 배포용

브라우저에서 URL로 접속해 이용하는 공개 웹앱입니다. 방문자가 **자기 OpenAI API 키**를 입력해 공개 네이버 블로그·카페 글을 최대 5개 분석하고 제목 추천, 문맥형 키워드 추출 및 다중 원고 생성을 이용합니다.

## 웹 배포 (사용자 PC에 Python 설치 불필요)

1. GitHub에 로그인해 새로운 저장소(repository)를 만듭니다. 공개(Public) 저장소도 됩니다.
2. 이 압축 파일을 **풀고**, 내부의 `app.py`, `requirements.txt`, `.streamlit` 폴더, `README.md`, `.gitignore`를 저장소 **최상위 폴더**에 업로드합니다. (ZIP 그대로 올리면 안 됩니다.)
3. [share.streamlit.io](https://share.streamlit.io/)에 GitHub 계정으로 로그인합니다.
4. **Create app / Deploy a public app**에서 본인 GitHub 저장소를 선택합니다.
5. **Branch**는 `main`, **Main file path**는 `app.py`로 설정합니다.
6. Deploy를 누릅니다. 앱 주소는 `https://...streamlit.app` 형태입니다.
7. 앱 주소를 다른 사람에게 공유하면, 접속자가 웹사이트에서 **자신의 API 키**를 입력하고 사용할 수 있습니다.

### API 키 및 공개 운영 주의 사항
- **OpenAI API 키를 GitHub 소스코드나 Streamlit Secrets에 등록하지 마세요.** 이 앱은 방문자가 개인 API 키를 입력하도록 되어 있습니다.
- OpenAI API 과금은 **각 이용자가 입력한 키의 소유 계정**으로 청구됩니다. ChatGPT Plus 구독과 별도입니다.
- API 키는 `type=password` 입력 UI로 받으며 파일에 저장하지 않습니다. API 호출 시 앱 서버에서 OpenAI로 전달합니다. 서비스 운영자는 서버 접근권한을 가지므로 신뢰할 수 있는 배포 환경에서 운영하세요.
- 공개 페이지는 검색·접속 가능한 상태이므로 주소만 아는 사람으로 접근을 **제한하는 방식은 아닙니다**. 주소를 아는 사람 누구나 접속해 자기 키를 입력할 수 있게 구성했습니다.
- 방문자별 작업은 Streamlit 세션 단위로 분리되며 영구 저장하지 않습니다. 새로고침/세션 만료 시 데이터가 사라질 수 있습니다.
- 추출이 막힌 네이버 카페 회원 전용 글이나 로그인 제한 글은 가져올 수 없습니다. 수동 본문 붙여넣기를 사용하세요.

## 화면 사용 순서
1. 사이드바에 본인의 OpenAI API 키, 분석/생성 모델 설정
2. 메인키워드 입력
3. 네이버 링크 최대 5개 입력 후 `① 5개 글 가져오기`
4. `② 5개 글 AI 분석` 버튼 → 유사 제목과 핵심키워드 및 근거 문장 확인·수정
5. 원고 작성 프롬프트와 원고 개수 설정 후 `③ 분석된 글 모두 원고 생성`
6. TXT 또는 CSV 다운로드

## 문제 해결
- `ModuleNotFoundError`: GitHub 저장소 최상위에 requirements.txt가 있는지 확인
- `File does not exist: app.py`: Main file path를 `app.py`로 설정했는지 확인
- `model_not_found`: 계정에 모델 접근권한이 없거나 모델 ID가 잘못됨. 다른 모델 선택 / 모델 ID 직접 입력
- `429` 오류: API 사용량 한도 또는 결제 크레딧 확인
- 네이버 글 읽기 실패: 네이버 로그인·페이지 구조·접근 제한 등으로 추출이 불가능할 수 있음

네이버 콘텐츠 사용권과 플랫폼 이용 정책을 준수하세요. AI 생성 원고의 사실관계는 게시 전에 확인하세요.
